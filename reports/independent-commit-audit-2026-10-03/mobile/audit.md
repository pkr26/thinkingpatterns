# Independent audit of mobile changes in ad797b0

The original commit's mobile suite passed 2,250 tests before this audit. Independent source review and adversarial scheduling nevertheless found twelve remaining defects. All twelve are fixed in the working tree, with 26 additional regression cases. The final unchanged suite passes **2,276 tests across 110 files**, with the original one intentional skip and all coverage gates retained. Verification was completed before publication. This follow-up commit includes the fixes and evidence; no deployment, production credential or release signing change was made.

This audit read the original M01–M25 finding map, mobile ownership/native-generation reports, the affected production code, tests, dependency backports and native project configuration. The controls use shipping cryptography and API/storage modules with explicit native/transport seams. They do not certify hardware flush durability or iOS device behavior.

The original launcher/native registration, real press-event submission, recovery token/scheme checks, edited-entry metadata, playback ownership/zeroization, localized labels, notification readiness, conflict retry, cadence and bounded insight payload behavior were read against the source and exercised by the unchanged full suite. The audit did not find additional reproducible defects in those source paths. Existing emulator logs in the original commit are historical evidence, not a new independent emulator run in this audit.

Full Xcode is unavailable (`xcode-select` points to CommandLineTools), so iOS compilation, signed archive resources, physical screen capture shielding, HealthKit writes, biometric user presence and delivered OS notification timing remain unverified here. Production HTTPS origin/signing remain operator configuration; the Android artifact is a debug build. Native share consumers, physical recording/playback and hardware flush guarantees likewise require device testing. The JS ownership registry provides one-runtime draining and generation fencing, not native cross-process CAS or proof of every competing-device recovery interleaving.

Exact reproducible commands are in [commands.txt](commands.txt). SHA-256 hashes of all eighteen changed mobile source/test files and every retained log are in [manifest.json](manifest.json). All test credentials, ciphertext and origins in these regression logs are synthetic fixtures.
