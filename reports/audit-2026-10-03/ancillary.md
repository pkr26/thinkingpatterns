## Confirmed defects

1. **High operational impact: invalid development Compose YAML.** `docker-compose.dev.yml:49` indents `audio-minio.image` at 12 spaces while sibling `command` at line 50 is at four. Complete YAML parse fails with expected-block-end error, so the README development overlay cannot start. No containers were run.
2. **Medium CI quality: all three JS mutation-score gates report failure for passing scores.** `.github/workflows/mutation-mobile.yml:93`, `mutation-portal.yml:84`, `mutation-web.yml:84` end their run blocks with `awk ... && { ... exit 1; }`. A score above its floor gives awk exit 1 and becomes the final step status; below-floor scores execute exit 1. The primary audit independently reproduced scores 64/65/90. Replace the final AND-list with a conditional whose successful case exits zero.
3. **Medium CI coverage: voice-campaign completeness is not enforced.** `redteam/run_all.sh:37` executes `g_voice.py`; `.github/workflows/redteam.yml:157` expected-results set omits `g_voice`. Runner warns on a nonzero campaign and finishes with the summary status. A pre-dump import/process failure can therefore leave no voice results without failing the weekly gate. A voice ERROR row that actually gets dumped is caught; the missing-file case is the gap.
4. **Medium recovery documentation: shipped backup inspect command fails with file-mounted secrets.** `backup/README.md:17` uses `openssl ... -pass env:BACKUP_KEY`; production `docker-compose.yml:293-294` permits an empty BACKUP_KEY and supplies BACKUP_KEY_FILE. HMAC verification resolves the file correctly, but the following decrypt receives the empty env value. Use the same file/env resolution as the backup writer.
5. **Medium test-evidence fidelity: frontend pin-kill verifier misclassifies runtime errors as kills.** `redteam/mutation_campaign_2026-09-22_frontend/verify_kills.js:25-47` stores only surviving after-mutants, then attributes every absent earlier survivor as killed. A safe `/tmp` synthetic report with Survived -> RuntimeError printed `killed by the pin batch: 1`, score `0.0%`, exit 0. A missing mutant or changed scope also counts as a kill. Require the matched after-mutant's Killed/Timeout status and validate scope/source before attributing kills.
6. **Low documentation/test coverage drift: “every endpoint” is stale.** `README.md:731` and `reports/simulation1y/SIMULATION_REPORT.md:14` say every route. Current backend has 67 API decorator routes; script contains no calls for POST /auth/recover; GET/PUT/DELETE /account/recovery; PUT /account/recovery/password; PUT /therapist/notes/rekey; DELETE /therapist/notes/{note_id}. Recovery/rekey were added after the dated run, but a current all-route guarantee is still unsupported. Therapist audio playback is covered through dynamic paths. Add endpoint-inventory enforcement or label the campaign as historical and explicitly scoped.
7. **Low fixture fidelity: combining-mark AAD case changed during promotion.** `redteam/aad_corpus.json` case `combining` uses NFD `e + U+0301` in `éclair-1`; `shared/vectors.json` uses NFC `éclair-1` and different expected bytes. Thus this promoted case no longer guards the original combining-mark contract. Fifteen other named AAD cases match byte-for-byte after hex/base64 conversion.
